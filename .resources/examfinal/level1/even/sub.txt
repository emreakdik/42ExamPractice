Assignment name  : even
Expected files   : even.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes any number of integers as arguments and displays
the even ones, one per line, in the order they were given.

If the program is called without arguments, it displays nothing.

Examples:

$> ./even 1 2 3 4 | cat -e
2$
4$
$> ./even -7 -4 0 | cat -e
-4$
0$
$> ./even | cat -e
$> ./even 1 3 5 | cat -e
