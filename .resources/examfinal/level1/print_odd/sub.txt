Assignment name  : print_odd
Expected files   : print_odd.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes one integer n and displays every odd number from
1 up to n included, one per line.

If n is smaller than 1, or if the number of arguments is not 1, the program
displays nothing.

Examples:

$> ./print_odd 6 | cat -e
1$
3$
5$
$> ./print_odd 1 | cat -e
1$
$> ./print_odd 0 | cat -e
