Assignment name  : interval_spaces
Expected files   : interval_spaces.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes two integers a and b and displays every number
between them, separated by a single space, followed by a newline.

The interval includes a and b. If a is greater than b, the numbers are
displayed in descending order.

If the number of arguments is not 2, the program displays only a newline.

Examples:

$> ./interval_spaces 3 7 | cat -e
3 4 5 6 7$
$> ./interval_spaces 2 -2 | cat -e
2 1 0 -1 -2$
$> ./interval_spaces 5 5 | cat -e
5$
$> ./interval_spaces 1 | cat -e
$
